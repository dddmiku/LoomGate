# 请求记录同步、账号活动与选号

## 页面行为

- 请求记录页默认每 3 秒做一次可见页面只读同步。通过快照 revision 只返回未变化描述；没有变化不重绘表格。隐藏页面、离开路由或手动暂停后停止请求，回来补读；断线退避，认证失效停止。
- 展开详情按真实 request_id 保留，不按行索引绑定。正在翻历史页、滚动阅读或选择文本时，新记录只给提示；点击提示才回到最新记录，避免挤走阅读位置。
- 账号原“会话与连接”列替换为“活动时间”，删除固定客户端说明。显示最近完成的模型尝试（结束时间缺失时仅显示真实发起时间）、模型、状态、近 24 小时成功/失败/取消尝试和最近请求入口；活动单独每 5 秒读本机日志，不附带钱包刷新。

## 数据口径

活动仅来自已完成并留存的真实上游尝试，不以凭据更新时间、余额查询、登录初始化或客户端连接核验充当模型活动。重试按每次真实上游尝试归属，整次请求状态与本账号尝试状态分开。没有记录只能说“留存内暂无”，不能当作从未调用或当前空闲。历史尝试、身份或留存有缺口时提示不完整；这不是永久累计账本，也不是进行中请求看板。

活动与快照接口只走已有内部管理通道，面板仍需登录。账号标识投影后合并旧/新别名；不返回凭据、原始手机号、请求正文或上游错误正文。日志存储格式和累计用量账本不变。

## 账号池核对

- WorkBuddy/Trae 原池已有收费模型临期积分优先、非临期粘性账号让路和不可用兜底；免费模型不强挤临期账号。本轮不重写这套策略。
- AutoClaw 原来是整体轮转。本轮改为：已有新鲜、可用、正数临期积分观测的账号优先，优先组内部公平轮转；没有可靠观测则普通轮转。显式指定账号不覆盖，也不推进自动选号游标；禁用、冷却、有限重试和输出后不拼接规则保留。
- 选号只读现有钱包缓存，观测有效期沿用 60 秒，不在模型请求里发钱包请求、短信、初始化或强刷。冷缓存、过期、错误或 pending 不猜成有效余额；正常余额任务/页面读回仍负责刷新观测，原定时开关不改。

## TTFB 与 total

本系统首包按首个可观测有效响应数据帧计时，而非 HTTP 响应头，也非完整答案。AutoClaw 直接记录上游 SSE 首帧，在下游转换/写出之前观测；没有观测保留未知，不用完成时刻补值。total 包含读入、排队、上游及下游收尾。新记录采用更细显示和原始毫秒提示；平均输出速度使用 total 减首帧耗时，无法计算则未知。

旧历史记录不回填或伪造。如果上游一次性返回、响应很短，或两次计时落在同一精度内，两者仍可能接近或相同；不会人为拉开数值。

## 验收

真实本地 Chromium fixture 覆盖自动更新、暂停恢复、阅读滚动、历史页、展开详情、账号活动及窄屏。Go 覆盖管理边界、快照版本、活动归属/别名合并、缓存临期优先与组内公平、过时/禁用/显式账号、首帧先于慢下游写出。测试使用合成账号与 transport，不能当作真实生产账号或积分消耗验证。完整精确源码发布结果见对应版本 FINAL-DELIVERY 回执；发布不等于生产已经更新。
