# 官方豆包登录与连接

Windows 工作台支持官方扫码、官方手机号登录和连接已有会话。选择方式后会打开独立的豆包窗口；手机号、验证码、扫码内容及安全验证均留在官方界面。工作台只保存身份摘要、账号修订号及连接证明。

需要免费积分和积分任务时，在官方账号选择页选择豆包账号，不选择“飞书个人版”。成功登录只证明身份有效；活动资格和任务列表仍由当前账号的官方响应决定。没有活动入口时，任务页提示核对账号，而不生成默认任务。

## 运行依赖

- Windows 已安装官方豆包客户端。
- Python 3，以及 `tools/doubao-runtime/requirements.txt` 中的依赖。
- 桌面分发包包含固定清单内的 `doubao-runtime` 组件。组件目录中不包含 profile、账号库或捕获数据。

桌面启动器寻找可运行的 Python；网关从配套运行目录寻找连接组件。普通用户不需要配置调试端口。客户端使用数据目录内受保护的 `official-client/profile`，不附着日常豆包实例，也不修改系统代理或证书。依赖缺失或客户端不可用会明确失败，不能当作登录成功。

开发时可设置 `LOOMGATE_DOUBAO_DESKTOP_PYTHON` 和 `LOOMGATE_DOUBAO_DESKTOP_HELPER` 指向绝对路径，不设置 `LOOMGATE_DOUBAO_DESKTOP_PORT` 即使用受控模式。显式指定端口仍保留为旧开发绑定路径；该路径不是新的短信或扫码登录。

## 生命周期与恢复

`authflow.PreparedStarter` 在任何外部操作之前，将登录意图写入加密流程存储。官方窗口打开操作在私有 journal 中先记账；重启和轮询只检查已有尝试。前端支持继续当前窗口、只读核验和取消，不会自动重发短信或生成新的二维码。

`ManagedConnection` 处理官方窗口状态，并复用 `DesktopConnection` 的身份复核、账号 CAS 和幂等提交。保存前再次读取官方身份和签名模型目录；账号被切换、修改或停用时拒绝覆盖。已有会话单独标识为 `existing_session`，不能算作新登录。

`ManagedCommand` 使用有超时的私有进程管道。组件验证专用 profile、可执行文件、进程创建时间、参数和回环监听归属。缺少进程或端口被占用时不接管其他进程。重启网关会为已启用账号恢复独立官方客户端，不创建登录流程；停用账号不会被自动启用。连接失败不阻塞其他 provider。

取消进行中的操作可能留下不确定结果。反复取消不能清除该状态或重放操作，必须先核验。MFA 和未知官方状态保留具体人工待办，不伪装成验证码错误或自动绕过验证。

如果用户在流程过期后才完成官方登录，进入原流程，点击“核验已完成的官方登录”。工作台新建 `desktop` 核验流程并标记 `existing_session`，通过身份和签名目录验证后才允许另行保存；原流程继续显示已过期。此操作不发送短信、不创建二维码，也不会把原过期登录改为成功。请求结果不确定时，从接入进度读取已有流程，不自动重试保存。

官方安全验证使用 `official_mfa_required` 状态，敏感字段只能在官方窗口输入。刷新页面可恢复待办，取消与到期不会延长登录时限；MFA 提醒按流程单独去重。官方会话失效时，账号显示需要登录；官方客户端恢复有效会话后可以恢复 ready，读取状态不会改写账号凭据、修订号或停用状态。并发续期保存使用 CAS，旧流程不能覆盖新绑定。

冷启动尚未产生官方窗口操作记录时，用户可显式继续当前流程；组件先等待官方页面就绪。已经写入窗口操作记录的尝试不会重新打开登录窗口。同一尝试不能切换登录方式，已过期或取消的记录不能被继续为新登录。

## 验证边界

2026-11-17 本机已实测：官方扫码后通过旧绑定路径保存及重启读回；通过新受控路径打开官方手机号窗口、用户完成短信登录、身份与动态目录复核、加密保存；网关正常退出与重启、停用状态保持、账号显式恢复，以及真实任务目录和响应式界面。

本次短信账号与之前扫码账号不同。短信账号官方目录返回 12 个模型、7 项任务和 3 项阶段奖励，仅是本次响应快照；源码没有固化这些列表。任务未执行、奖励未领取。

新增实测：受控模式创建官方二维码，用户完成扫码与手机确认。确认时原流程已经过期；工作台保留过期记录，经上述已有会话入口保存一次，并在网关正常退出、重启后读回成功。该扫码身份与短信身份不同，分别保留；扫码账号当次官方响应也返回 12 个模型、7 项任务和 3 项阶段奖励。活动入口可用不代表奖励到账。

独立官方客户端完全退出后的恢复已实测：进程被范围核验后的终止操作结束，网关读到 disconnected；随后正常重启网关，自动启动原 profile 并验证同一身份、目录和账号修订号。此结果属于进程终止恢复，不代表官方客户端优雅退出。

仍未覆盖：受控 QR 在流程有效期内直接保存、真实 MFA（未触发）、官方会话自然过期与续期（NOT RUN）。MFA、失效恢复、并发续期和过期后恢复已有会话有合成回归，不能冒充这些真实场景。Windows 新安装包和 Android/Linux 本轮未重新构建；本轮 Windows 开发网关构建通过。原 Windows 安装包验收是上一阶段结果，不能覆盖本次改动。生产切换仍需独立验收。
