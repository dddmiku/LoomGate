# 账号会话保活

`keepalive` 是 WorkBuddy 国内、国际与 Trae 的独立生产任务模块。生产组合提供 `RefreshVault` 时注册，页面通过真实任务目录发现。逐项或当前范围执行、时间/时区/账号范围/开关、计划持久化与取消恢复均复用统一引擎，不再调用旧调度器。

## 操作和保存

目录读取只检查本地会话与恢复记录，不刷新、不注册账号、不生成内容。执行使用官方 WorkBuddy token refresh 或 Trae ExchangeToken 路径，单次可取消请求，有30秒期限，不跟随重定向，不输出响应或凭据。WorkBuddy要求明确业务码及合法有效期；Trae要求正式 Result.Token 与支持的秒/毫秒有效期，缺字段不能成为接受证据。

刷新响应先保存到现有AES-GCM安全库的固定账号记录，再用凭据修订校验原子写回原兼容账号文件，最后发布到内存。网络调用不持有凭据锁。内存修订和磁盘文件均检查，其他登录已改凭据时不覆盖。已有账号文件保持原兼容格式和已有保护；本阶段没有把整个旧账号库改造成加密库，也没有执行生产迁移。

真实保存失败但响应已安全落盘时，原运行保持待核验。后续恢复只采用同一个已保存响应，重新保存并读取文件确认，不再向上游刷新。响应丢失且无可信记录则保留未知；不会因为令牌仍有有效期就假定本次刷新成功。单飞刷新复用现有 Auth 协调，等待者可取消；持久凭据回读与任务证据都不能含原文token。

## 停用规则

只有明确 `12153 session dead` 停用的账号允许保活模块发现和恢复，普通任务仍不使用它。WorkBuddy明确12153拒绝沿用原连续三次阈值；传输失败和格式变化不累计为会话死亡。已成功保存并回读后，锁内再次确认账号对象和停用原因，仅恢复会话失效标记。人工停用、内容审核标记、其他停用原因和刷新期间新发生的人工停用都不会被自动启用。

启用账号上的余额耗尽、模型限制及其说明保持原状。续期只证明会话更新，不证明额度或其他上游限制已解除。

保留原账号域；旧空realm在安全写入时按原domain补齐。旧实现按出口IP自动补注册国家的流程没有照搬：这属于额外账号资料/注册操作，仍需在官方界面核验，不能用续期成功冒充注册已完成。

## 验证与边界

生产模块、真实HTTP/账号池/加密库及浏览器已验证：三个域、发现零刷新、按范围续期、真实文件回读、会话失效恢复、人工/审核保护、并发重登、外部文件替换、取消等待、严格信封、丢响应禁止重放、保存失败后重启恢复。浏览器还验证自由时间/时区、计划启停和实际进程重启持久化。

上述上游与账号全部为隔离合成数据。真实账户续期、国家注册确认、正式短信/扫码/MFA、完整旧生产账号迁移与签名信任链为 `NOT RUN`。旧系统保持运行，未启用新旧双派发或生产切换。
